# Design direction

SEO Analyzer is a browser inspection bench for an HTML snapshot. It keeps the
source specimen and lint ledger adjacent so the visitor can connect each result
to the markup that produced it.

- Palette: warm paper, cobalt ink, acid-green pass state, and coral failure
  state.
- Type: Plus Jakarta Sans is the readable surface voice; Azeret Mono is used
  for source, counters, and diagnostic labels.
- Form: source-to-report split, a diagnostic ledger, status marks, and a score
  bar rather than a generic dashboard card stack.
- Content truth: checks run only against the HTML in the editor. The URL is a
  label, not a request target, and the page makes the no-crawl boundary clear.
- Responsive rule: source stacks above report and long check details move under
  their check names on narrow screens.
